Light Xi contour stress harness
===============================

This is a tighter stress sweep that completes quickly.

It sweeps:
- radius in {0.60, 0.75, 0.90}
- N in {128, 256}
- contour dps in {25, 35}

against a derivative baseline.

Outputs
-------
- xi_jensen_contour_stress_light_results.csv
- xi_jensen_contour_stress_light_summary.txt

Use this to choose a better contour configuration before larger runs.
